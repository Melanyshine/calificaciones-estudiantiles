# calificaciones-estudiantiles
# Sistema de Calificaciones Estudiantiles

# Descripción
Este proyecto es un sistema de calificaciones estudiantiles permite calcular el promedio de un estudiante a partir de cuatro notas y determinar si está aprobado o reprobado, aplicando las reglas de completivo y extraordinario según lo establecido.

# Objetivo
Aplicar la lógica de programación vista en clases para el manejo de calificaciones, validaciones y cálculo de notas finales mediante un formulario interactivo.

# Funcionamiento del sistema
- El usuario ingresa cuatro calificaciones.
- El sistema calcula el promedio automáticamente.
- Si el promedio es mayor o igual a 70, el estudiante queda Aprobado.
- Si el promedio es menor a 70:
  - Se habilita el campo de Completivo.
  - La nota final se calcula con un 50% del promedio y 50% del completivo.
  - Si aún no alcanza 70, se habilita el Extraordinario.
  - La nota final se calcula con un 30% del promedio y 70% del extraordinario.
- El sistema muestra el resultado final: Aprobado o Reprobado.
